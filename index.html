01

Recent 6 · Token Monitor

状态在边上，
注意力留在任务上。

六条边对应最近六个 Task。颜色先告诉你哪里正在运行、哪里需要回应；中央只呈现当前可见 Task 的生成节奏与额度概览。

tok/s 仅统计当前可见 Task 的 output 与 reasoning output。Weekly、剩余 Token 与可用时长为本机校准估算，并非 OpenAI 提供的精确额度。

从 Compact 到完整状态

Compact Monitor 默认仅显示 Weekly 剩余比例 68%。展开为 Recent 6 后，五种状态依次突出；中央显示 24.6 tok/s、Weekly 68% 与本机估算。

状态会自动循环。选择任一状态可暂停循环，并突出轮盘中对应的边。

02

Controller & Pointer

一个六边形，
两种自然的控制方式。

按住 L，用右摇杆选中 Task，松开立即切换。手离开手柄时，也可以拖动 Monitor、展开 Recent 6 并直接点击任务。

  1. 按住 L从 Compact Monitor 展开 Recent 6。
  2. 推动右摇杆颜色与 Task 名称同步高亮。
  3. 松开 L精确切换到对应 Task；B 随时取消。
  1. 拖动把 Compact Monitor 放在顺手的位置。
  2. 展开Force Touch 或右键打开 Recent 6。
  3. 点击 Task切换任务；点击中央即可收起。
切换到「完善首页」Recent 6 已展开

Cohex 的悬浮 Monitor 不抢走 Codex 输入焦点。拖动它改变位置；Force Touch 或右键展开；点击 Task 切换，点击中央收起。

一次播放的动画展示 Nintendo Switch Pro Controller：L 键发光，Recent 6 展开，右摇杆选择任务，松开后完成切换。

鼠标只直接操作 Token Monitor 与 Recent 6。Cohex 不会把手柄摇杆伪装成 macOS 系统光标。

为什么叫 Cohex

从 Codex，到六边形。

Cohex 由 Codex 与 Hex 融合而来。Co 保留它与 Codex 的连接，Hex 指向产品的六边形界面，也对应 Recent 6 的六个 Task。

标记以苯环的六边结构为灵感：六条边承载任务状态，中央圆代表当前聚焦的 Task。名字、图标与交互，因此共享同一种几何语言。

C hex

六个 Task，一眼掌握。

Cohex 是独立项目，与 OpenAI、Apple、Nintendo 或 Work Louder 无隶属、赞助或背书关系。所有产品名称与商标归其各自所有者。

页面动画使用匿名固定示例，不读取本机 Task、Token 或任何个人数据。
